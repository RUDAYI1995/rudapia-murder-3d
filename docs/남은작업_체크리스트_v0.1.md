## 처리 순서 제안

1. **A6~A9** 검수 (이미지 안 받아도 지금 가능) — 구역 02 홀을 먼저 마감
2. **A1** 북쪽 벽 요청서를 ChatGPT에 보내고, 기다리는 동안 **C1** 동쪽 날개 요청서(v0.4) 작성
3. 이미지가 오는 대로 **A1 → A2/A3 → A4/A5 → B → C → D** 순으로 한 건씩 적용·검수
4. 틈틈이 **F1/F2**(엔진 품질) 처리
5. 맵 마감 후 **G2(사냥 프로토타입)** 부터 게임 기능 시작

## 진행 규칙

- 한 번에 한 건씩 처리하고, 끝나면 이 표의 상태를 ✅로 바꾼다.
- 이미지 적용마다 **원본·백업 보관**, 화면 확인, 필요하면 감사·스윕 재실행.
- 각 항목의 완료 기준은 "화면에서 확인함 + 확인하지 못한 것은 따로 적음".
