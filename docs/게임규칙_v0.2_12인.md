# 루다피아 은밀한 살인 — 게임 규칙 v0.2 (12인)

> 사람 1명 + AI 11명, 직업 12개를 한 명씩. 코드: `src/zone02/game/` (`game.js` 진행, `mind.js` AI의 기억·추리·대화, `roles.js` 직업, `audio.js` 효과음)
> ※ 표시: **[요청]** = 당신이 정한 규칙, **[가정]** = 정해지지 않아 제가 임시로 정한 것(바꾸고 싶으면 알려 주세요)

## 1. 인원과 직업 (12명, 직업 하나씩)

| 팀 | 직업 | 밤 능력 |
|---|---|---|
| 시민팀 | 의사 | 밤마다 죽을 것 같은 1명에게 약을 준다(가까이 가면 건넴). 그 사람이 죽기 전에 약을 먹어 **1번** 산다. 약으로 살린 사람에겐 다시 줄 수 없다. 또 습격당한 사람을 **5초 안에** 곁에서 치료하면 살린다. |
| | 경찰 | 밤마다 1명을 조사(가까이 가서 머문다) → 마피아팀/시민팀. 마피아팀이면 그 사람이 **강제 마피아 복장**이 되고, 경찰이 **긴급 호루라기(V)** 를 불 수 있다. |
| | 사립탐정 | **마피아의 발자국은 파랑, 마피아에게 죽은 사람의 발자국은 빨강**으로 보인다. 그 외 사람(본인 제외 전원)에게는 발자국이 보이지 않는다. |
| | 영매 | 죽은 사람이 유령으로 보이고, 유령과 대화해(G) 정보를 얻는다. |
| | 기자 | 카메라로 사진(C)을 찍고, 사진은 **사진첩(P)** 에 기록되어 모두가 본다. |
| | 자경단원 | 밤에 **딱 한 번**, 의심되는 1명을 골라 총을 쏜다(Space). 총은 자경단원만 쓴다. |
| | 군인 | 마피아나 자경단원에게 죽으면 **죽인 사람과 함께 죽는다**. |
| | 시민 | 능력 없음. |
| 마피아팀 | 마피아 | 밤마다 도구로 1명을 죽인다. **평소엔 시민인 척** 하다가 도구를 주울 때만 "정하림"으로 변신, **사냥이 끝나면 곧바로 시민 복장**으로 돌아온다. |
| | 스파이 | 밤마다 1명의 직업을 안다(아침에 결과). |
| | 추적자 | 밤마다 1명의 위치·행동을 파악한다(아침에 결과). |
| 제3세력 | 교주 | 밤마다 1명에게 포교(가까이 가서 머문다) → 사이비 광신도로 영입. **마피아팀은 "마피아"만 빼고** 영입 가능. |

## 2. 하루 흐름
1. **낮 (60초)**: 맵 전체를 돌아다니며 대화. AI끼리 가까이 있으면 밤에 본 것을 서로 이야기한다.
2. **투표**: 어디에 있든 **원탁 12석으로 소집**. 토론(38초) → 투표(20초) → 과반수면 처형 컷신(직업 공개).
3. **밤 (90초)**: 각자 흩어져 능력 사용. 마피아는 평소 시민처럼 돌아다니다가 사냥. 사냥에 당하면 **5초** 동안 쓰러져 있다가, 치료받지 못하면 사망.
4. **아침**: 사망자와 단서(도구, 장소) 발표, 개인 결과(스파이/추적자/경찰)는 **수첩(J)** 에.

## 3. 승패 **[가정]**
- **시민팀 승리**: 마피아팀과 제3세력이 모두 사라짐
- **마피아팀 승리**: 마피아팀 생존자 수 ≥ (시민팀 + 제3세력) 생존자 수
- **제3세력 승리**: 교단(교주+광신도) 생존자 수 ≥ (시민팀 + 마피아팀) 생존자 수
- 포교된 사람은 **광신도**가 되어 원래 직업 능력을 잃고 제3세력이 된다. 교주와 광신도는 서로를 안다.

## 4. 세부 규칙 (정해지지 않아 가정한 것)
- 투표 과반 = 생존자의 절반 초과. 동률이면 처형 없음.
- 약: 밤이 끝나면(아침) 사라진다. 습격당하면 소모되고 의사가 알게 된다(해당 사람에게 다시 줄 수 없음).
- 치료: 의사가 습격당한 사람 2.6m 안에 1초 머물면 치료. 의사는 5초 안에 도착해야 한다.
- 경찰 조사: 2.5m 안에 3.5초 머무르면 완료. 제3세력(교주/광신도)은 "시민팀"으로 나온다.
- 경찰 호루라기: 밤마다 1번. 모든 사람에게 소리가 들리고 AI 시민이 소리 난 쪽으로 몰려간다. (호루라기음은 WebAudio 로 합성)
- 강제 마피아 복장은 아침에 풀린다.
- 자경단원 사격: 10m 안, Space. 약이 있으면 약으로 막을 수 있다. 군인이 맞으면 군인과 쏜 사람이 함께 죽는다.
- 포교: 2m 안에 4.5초 머무르면 시도. AI는 35% 확률로 거부한다. 사람이 대상이면 항상 성공.
- 스파이/추적자/교주는 서로를 알아보는 방식: 마피아팀은 서로 안다. 교주는 광신도만 안다(마피아팀은 모름).
- 마피아가 죽어도 스파이/추적자가 있으면 마피아팀은 계속 싸운다(죽일 능력은 없음).

## 5. AI의 생각과 대화 (`mind.js`)
- **관찰**: 10m 안에서 같은 구역에 있거나 3.5m 안에 있는 사람이 **어디 있었는지** 기억한다. 가면 쓴 범인("정하림")을 보면 어디서, 어떤 도구를, 근처에 누가 있었는지 기억한다. 습격 장면, 시신 발견, 자기가 쫓긴 일도 기록한다.
- **쫓길 때**: 쫓기고 있으면 "누가 날 쫓아와!", "가면 쓴 놈이 따라와!" 라고 외친다(근처 사람들이 듣는다). 쫓겼던 일은 아침 토론에서 정리해서 말한다("어젯밤에 ○○에서 가면 쓴 놈이 식칼을 들고 따라왔어").
- **밤새 본 것 정리**: "어젯밤 나는 서재 → 홀 → 주방 순서로 다녔어. 홀에서 서윤을 봤고…"
- **추리**: 남의 알리바이가 내가 본 것과 다르면 의심하고 지적한다. 범인 근처에 있던 사람, 경찰 조사 주장, 탐정 단서, 사진 속 인물을 근거로 의심도를 올린다.
- **거짓말**: 마피아팀과 교주는 가짜 알리바이, 가짜 경찰 주장을 한다. 시민팀은 본 대로만 말한다.
- **반응**: 의심받으면 변호하거나 반박하고, 동료가 지목당하면 변호한다. 사람이 채팅(Enter)으로 이름을 부르며 묻거나 몰아세우면 그 AI가 대답한다.
- **투표**: 의심도, 경찰 주장, 모순을 근거로 투표한다. 마피아팀은 자기들을 겨눈 사람과 경찰이라고 주장하는 사람을 민다.

## 6. 조작
Enter 말하기 · Space 행동(사냥/사격) · C 사진(기자) · V 호루라기(경찰) · G 유령 대화(영매) · J 수첩 · P 사진첩 · X 도구 내려놓기(마피아) · Shift 달리기(밤 생존자는 체력제)

## 7. 아직 부족한 점
- AI 대화는 규칙 기반 템플릿이라 어색한 문장이 섞일 수 있다(진짜 사람처럼 자유로운 대화는 아님).
- 밸런스는 AI끼리의 시뮬레이션 몇 판으로만 확인했다(교주가 강할 때가 있고, 마피아팀 승리는 드물었다).
- 기자의 AI 사진은 후처리 없는 단순 렌더링이다.
- 서버 진실 기록(`g.rec`, 발자국 메타)은 브라우저 안에만 있다(서버 이전 필요).
