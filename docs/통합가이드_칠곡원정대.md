## 2. 이식 방법 (권장 순서)

### A. 가장 안전한 방법: "별도 페이지"로 붙이기
칠곡원정대가 Vite 프로젝트라면, 루다피아를 **하위 폴더 + 별도 HTML 엔트리**로 넣는다. 서로의 코드를 섞지 않는다.

1. `src/zone02/`, `src/data/zone02_layout.json`, `public/assets/zone02/`(필수 파일만), `tools/`(선택)를 칠곡원정대 프로젝트로 복사. 예: `src/rudapia/zone02/…`.
2. 루트의 `index.html`(HUD 포함)을 `rudapia.html` 같은 이름으로 복사하고, 스크립트 경로를 `/src/rudapia/zone02/main.js`로 수정.
3. Vite 멀티 페이지 설정(`build.rollupOptions.input`)에 `rudapia.html`을 추가.
4. `three`가 **0.186.x**인지 확인. 다른 버전이면 `three/addons/...` 경로와 GTAO 패치(아래 5번)가 깨질 수 있다.
5. 에셋 경로: `assets.js`의 `BASE = '/assets/zone02/'`. 칠곡원정대의 `public/` 구조에 맞게 바꾸거나 같은 경로로 복사.

### B. 맵만 라이브러리처럼 쓰기
`createWorld()`는 `scene`에 `Group`을 붙이는 구조라서, 칠곡원정대의 자체 씬에 맵만 추가할 수 있다. 이때 `main.js`의 렌더러/후처리/입력/낮밤 코드는 직접 옮겨야 한다. (난이도 높음. A를 먼저 하고 필요하면 분리.)

### C. 걷기만 가져가기
`walk-module/walk.js`(+README.md)를 쓴다. 충돌·카메라·입력만 있고 맵 의존성 없음.

## 3. 충돌 가능성 / 주의 (칠곡원정대와 합칠 때)

| 항목 | 내용 |
|---|---|
| **three 버전** | 0.186.x 기준. 다르면 `GTAOPass` 패치가 깨질 수 있음 |
| **전역** | `window.__dbg`(디버그 훅: hero, camera, scene, world, setNight, step, audit…). 이름 충돌 가능성 낮지만 확인 |
| **DOM id** | `#view #help #minimap #mapBtns #mapBtn #fsBtn #bigmap #bigmapCanvas #bigmapBar #mapClose #status #click #loading` — 칠곡원정대 HTML과 같은 id가 있으면 충돌 |
| **CSS** | `index.html`의 `<style>`이 body/canvas에 전역으로 적용됨. 별도 페이지로 분리하면 충돌 없음 |
| **키 입력** | WASD/Shift/Q/E/M/N/F/O/R, Esc. 칠곡원정대 키와 겹치면 `main.js`의 keydown 처리에서 수정 |
| **마우스 고정** | `canvas.requestPointerLock`. iframe/미리보기에서는 막힐 수 있음(왼쪽 드래그로 대체됨) |
| **성능** | 포인트 라이트 풀 22개, 후처리(GTAO+Bloom+그레이드), 렌더 해상도 1.35~1.75배. 낮은 사양은 `?q=low` |
| **후처리 패치** | `main.js`에서 `GTAOPass._overrideVisibility`를 패치(투명/셰이더 메시는 가림 계산에서 제외). three 내부 이름에 의존 |
| **메모리** | 절차적 텍스처를 시작 때 생성(약 5초). 로딩 화면(`#loading`)이 가려 준다 |

## 3-1. 알려진 한계 (정직하게)

- **캐릭터·가구·샹들리에·나무·분수·자동차는 임시 도형**이다. 3D 모델(glb)로 교체할 계획이지만 지금은 보류.
- 충돌은 **위에서 본 2D**(원 vs 축 정렬 박스). 계단·경사·점프 없음. 계단은 눈에 보이기만 하고 올라갈 수 없다(2층 없음).
- 벽·바닥 이미지 해상도: 홀 바닥 101 px/m, 홀 벽 약 144 px/m (4096 px 요청은 ChatGPT 한계로 미달).
- 동쪽 날개·서재·앞마당 건물은 벽/바닥이 아직 **코드로 만든 절차 텍스처**(이미지 교체 예정).
- 게임 규칙(역할, 투표, 사냥, 컷신, 서버)은 **없다**.

## 4. 에셋 파이프라인 (다른 그림으로 교체할 때)

원본 이미지 → 변환 도구 → `public/assets/zone02/` → `assets.js`가 로드 → `props/hall.js` 등이 배치.

| 에셋 | 원본(`assets/ref/hall/`) | 변환 | 사용 위치 |
|---|---|---|---|
| 홀 바닥 문양 | `floor-medallion-v2.webp` | `node tools/make-floor-hq.mjs` (`SIZE_M=12.4`) | `hall.js` 바닥 |
| 북쪽 벽(v2) | `wall-north-v2-27.webp`, `-29.webp` | `node tools/make-wall-sheets.mjs` | `hall.js` 북쪽 벽 |
| 동·서 벽 | `wall-eastwest-elevation-v2.webp` | 동 | `hall.js` |
| 남쪽 벽 | `wall-south-elevation-v2.webp` | 동 | `hall.js` |
| 초상화(큰) | `portrait-big-v2.webp` | `node tools/make-portrait.mjs <src> <name>` | `hall.js` 북쪽 벽 |
| 그 외 | `hall-*.webp` | `node tools/make-hall-assets.mjs` | 포트레이트, 태피스트리, 바닥 등 |

- 변환에는 `sharp`가 필요하다 (`npm i`).
- 벽 시트 규칙: 투명 PNG, 실루엣 높이 = 벽 높이 7 m, 좌우는 **기둥 중심선**에서 자른다 (자세한 건 `tools/make-wall-sheets.mjs` 상단 주석).
- 에셋이 없으면 코드는 **절차적 재질로 자동 대체**한다 (`assets.js`가 `null` 반환 → 호출 쪽 fallback).

### 칠곡원정대 그림 스타일로 바꿀 때 (Gemini 작업 지침)
1. 건물 구조(방 크기·문 위치)는 `zone02_layout.json`이 정한다. 그림은 **그 구조 위에 입히는 텍스처**일 뿐이다.
2. 새 그림은 위 표의 "사용 위치"와 같은 **규격(정면 정사영, 투명 배경, 조명 굽지 않음, 실제 크기 m 기준 px)** 으로 만들어야 이음새가 맞는다. 규격은 `docs/ChatGPT_에셋제작_요청서_v0.2_고해상도.md`와 `docs/ChatGPT_요청서_v0.3_홀북쪽벽_4096.md`에 있다.
3. 스타일이 크게 다르면(일러스트/카툰 등) `main.js`의 후처리(블룸·그레이드·AO)와 `NIGHT/DAY` 조명 프리셋(`main.js` 상단)을 같이 조정해야 어울린다.

## 8. 추가분 (2026-10-15 기준) — 게임 로직까지 포함해서 합칠 때

이 문서 작성 뒤에 **마피아 게임(12인)** 이 추가됐다. 맵만 합치지 말고 아래도 같이 가져가야 한다.
