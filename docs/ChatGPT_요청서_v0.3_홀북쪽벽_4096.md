# ChatGPT 요청서 v0.3 — A1. 중앙 홀 북쪽 벽 (4096 px 필수)

> 작업 번호: **A1** (`docs/남은작업_체크리스트_v0.1.md`)
> 대상: 중앙 홀 북쪽 벽(대계단 뒤쪽). 실제 크기 **20 m × 7 m** = 모듈 3장(각 6.667 m × 7 m).
> **필수 해상도: 각 이미지의 높이(실루엣 위끝~아래끝) = 4096 px 이상.** 이보다 작으면 불합격이며 다시 만든다.

---

## 0. 먼저 읽을 것 (유저용)

- 아래 **"붙여넣기용 프롬프트"** 를 그대로 ChatGPT에 붙여넣는다. 모듈 3장은 **한 대화 안에서 차례로** 만들게 한다(같은 스타일·같은 높이 유지를 위해).
- 4096 px가 **반드시 지켜져야** 하므로, 프롬프트에 "해상도가 안 나오면 알려라"가 들어 있다. ChatGPT가 실제 크기를 말하면 그걸 그대로 저에게 전달해 주세요.
- ChatGPT 이미지 도구가 4096 px를 못 만들면: ① 가능한 최대 크기로 받고 ② 업스케일러(Upscayl 등)로 4096 px까지 키운다. (자세한 순서는 5번)

---

## 1. 붙여넣기용 프롬프트 (1/2): 공통 규칙 + 첫 모듈

```
게임용 3D 벽 텍스처 이미지를 만들어 줘. 아래 규칙은 전부 필수야. 하나라도 어기면 다시 만들어.

[이미지 종류]
- 신고전주의 대저택 중앙 홀의 북쪽 벽 정면 입면도(elevation). 실제 크기 폭 6.667m × 높이 7m 한 칸(모듈).
- 크림색 대리석 + 금색 몰딩 + 갈색 대리석 패널. 코린트식 기둥머리, 치아 모양(덴틸) 몰딩, 위쪽 띠(프리즈) 패널, 하단 걸레받이 패널을 정교하게.

[필수 해상도 — 가장 중요]
- 이미지 높이 4096px 이상. (벽 실루엣의 맨 위 처마 장식 끝부터 맨 아래 받침 끝까지가 4096px)
- 폭은 약 3900px.
- 요청한 해상도가 안 나오면 임의로 줄이거나 억지로 키우지 말고, 실제로 나온 가로×세로 픽셀 수를 정확히 알려 줘.

[구도]
- 완전한 정면 정사영(orthographic). 원근·소실점·광각 왜곡 금지.
- 좌우 끝은 기둥(필라스터)의 "중심선"에서 정확히 잘라서, 장식이 반쪽만 보이게 해 줘. 옆 모듈과 이어 붙였을 때 이음새가 안 보여야 해.

[배경]
- 배경은 진짜 투명(알파 채널) PNG. 안 되면 순백 #FFFFFF 단색. 체크무늬(가짜 투명)·회색 배경·그라데이션 금지.

[조명]
- 조명·그림자·비네팅·바닥 그림자를 그리지 마. 밝기는 균일하게(flat lighting). 조명은 게임에서 넣을 거야.

[금지]
- 사람, 가구, 계단, 카펫, 화분, 촛대, 샹들리에를 그리지 마.
- 초상화, 그림, 흉상, 태피스트리를 그리지 마. 액자 자리와 벽감 안쪽은 "비어 있는 대리석 면"으로 둬.
- 가로줄·격자 무늬·번짐·노이즈·AI 특유의 깨진 선 금지. 선은 날카롭게.
- 업스케일로 뭉갠 느낌 금지.

[이번 모듈: N-1 (왼쪽 칸)]
- 왼쪽 끝은 홀의 "모서리 기둥", 오른쪽 끝은 일반 기둥(중심선에서 자름).
- 구성(왼쪽→오른쪽): 모서리 기둥 – 아치형 오목한 벽감(폭 약 1.1m, 높이 약 2.6m, 안은 비어 있음, 아래에 받침 선반 장식) – 기둥 – 큰 오목한 액자 자리(안쪽 약 1.6m × 2.2m, 비어 있는 대리석 면, 위에 장식 캐피털과 금색 장식) – 기둥 – 아치형 비어 있는 벽감 – 일반 기둥.
- 파일: PNG.
```

## 2. 붙여넣기용 프롬프트 (2/2): 나머지 모듈 2장

N-1을 받고 마음에 들면, 같은 대화에서 아래를 차례로 보낸다.

```
방금 만든 N-1과 완전히 같은 스타일·같은 높이·같은 처마 높이·같은 몰딩 라인·같은 기둥 모양·같은 4096px 높이로, 두 번째 모듈 N-2를 만들어 줘.
- 왼쪽 끝과 오른쪽 끝 모두 일반 기둥 중심선에서 자름. N-1의 오른쪽 끝과 N-2의 왼쪽 끝이 이어 붙였을 때 선과 장식이 정확히 이어져야 해.
- 구성은 N-1과 같되 대리석 결과 세부 장식은 반복처럼 보이지 않게 다르게.
- 초상화·흉상 없음, 액자 자리·벽감은 비어 있음.
- 해상도가 안 나오면 실제 가로×세로 픽셀 수를 알려 줘.
```

```
같은 방식으로 세 번째 모듈 N-3을 만들어 줘.
- 왼쪽 끝은 일반 기둥(N-2의 오른쪽 끝과 이어짐), 오른쪽 끝은 홀의 "모서리 기둥".
- N-1을 좌우 반전한 구성이어도 좋지만, 대리석 결은 N-1과 다르게.
- 나머지 조건(4096px, 투명 배경, 조명 없음, 비어 있는 자리)은 동일.
```

## 3. 이미지 규격 요약

| 항목 | 기준 |
|---|---|
| 모듈 크기 | 6.667 m × 7 m (폭 약 3900 px × 높이 **4096 px 이상**) |
| 해상도 | **약 585 px/m** (현재 163 px/m의 3.6배) |
| 높이 기준 | 실루엣 위끝(처마) ~ 아래끝(받침) = 7 m = 4096 px |
| 좌우 끝 | 기둥 중심선에서 잘림 |
| 배경 | 투명 PNG(또는 순백) |
| 조명 | 없음(균일) |
| 비어 있어야 할 곳 | 큰 액자 자리(1.6×2.2 m), 아치 벽감(1.1×2.6 m) |

최소안: 모듈 1장만 받아도 된다(3번 반복해서 사용). 단 4096 px는 동일하게 필수.

## 4. 합격 기준 (제가 받은 뒤 검사)

1. 높이 4096 px 이상, 알파 채널 있음(또는 순백 배경).
2. 실루엣 높이 = 가로 폭의 약 1.05배(= 7 m : 6.667 m).
3. 좌우 끝이 기둥 중심선에서 잘림, 인접 모듈과 선이 이어짐.
4. 가로줄·노이즈·가짜 투명(체크무늬) 없음.
5. 액자 자리·벽감이 비어 있음.

하나라도 불합격이면 어떤 항목인지 알려 드리고 재요청 문구를 드린다.

## 5. 4096 px를 못 얻을 때

ChatGPT 이미지 도구는 보통 1500 px 안팎까지만 출력한다. 이때는:

1. 가능한 최대 크기로 모듈을 받는다(위 프롬프트의 "실제 픽셀 수 알려 줘" 활용).
2. **배경을 순백으로 받은 상태에서** 업스케일러(Upscayl, Real-ESRGAN, Topaz Gigapixel)로 약 3배 키워 높이 4096 px 이상을 만든다. (업스케일러가 알파를 지우는 경우가 있어 순백 배경이 안전하다. 배경 제거는 제가 한다.)
3. 업스케일 옵션은 "디테일을 새로 지어내지 않는 모드", "조각 반복 무늬 방지"로.
4. 결과 파일을 저에게 준다.

## 6. 받은 뒤 제가 하는 일

1. 위 4번 합격 검사.
2. 배경 제거(순백이면), 실루엣 높이 정규화(=7 m), 모듈 이음새 검사.
3. `tools/make-wall-sheets.mjs`에 `wall_north_1/2/3` 추가, `hall.js`에서 **3모듈을 서로 다른 이미지로** 배치.
4. 비어 있는 큰 액자 자리·벽감에 **초상화를 별도 이미지로 걸기**(A2, A3).
5. `__dbg.audit()`로 px/m 확인, 어둠·과노출 스윕 재실행, 체크리스트 A1을 ✅로.
