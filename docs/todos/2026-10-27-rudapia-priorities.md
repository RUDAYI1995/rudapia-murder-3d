## 다음 작업을 시작할 때

이 문서는 사용자가 다음 작업에서 우선순위를 이어가도록 요청한 장기 보존 문서다. 저장소 루트 `AGENTS.md`에서 이 문서를 먼저 읽도록 안내한다.

- 실제 파일·Git 상태·실행 화면을 먼저 확인한다. 문서만 보고 현재 상태가 그대로라고 가정하지 않는다.
- 사용자의 최신 요청을 우선한다. 별도 변경 지시가 없으면 아래 우선순위에서 이어간다.
- 현재 체크포인트는 원본 기준의 맵 구도·배치 이동까지다. 최종 그래픽, AI 모드, 친구들과 온라인 플레이가 완성된 상태가 아니다.
- 현재 시각 결과를 원본과 동일하게 완성했다고 보고하지 않는다. 남은 차이를 실제 비교 화면으로 확인한다.

## 현재 구현 상태

- Three.js·Vite 웹 프로젝트다. 기본 주소 `/`에는 이전 프로토타입 게임이 남아 있다.
- `/?look=reference`와 `/?look=horror`는 원본 재현 미리보기다. 이 화면에서는 게임 시작 UI를 숨기고 회의용 NPC를 생성하지 않는다.
- 복도 끝 인물은 정적인 3D 모델이며 판단하는 AI가 아니다.
- 원탁·의자·샹들리에·수납장·아치 창·문틀·벽등·작업등·모니터·생존자를 독립 GLB 10종으로 제작했다.
- 원본 화면 비율 1344×768, 원본 구도 복귀, 걷기, 복도 이동, 원본 사진 비교를 제공한다.
- 구도 수정에서 카메라를 뒤로 이동하고 화각을 좁혔다. 창 높이·창턱, 홀 폭·깊이, 원탁·의자·수납장·샹들리에·모니터 위치, 복도 폭·높이·방향, 인물 위치·경계 포즈를 조정했다.
- 복도와 수납장 이동에 충돌 위치도 함께 갱신했다.
- 재현 화면은 직접 작성한 모델과 재질을 사용한다. `public/assets/horror/`는 이전 시안 자료이며 현재 재현 경로에서 사용하지 않는다. 임의 삭제하지 않는다.

## P3 — 개인 기억·성격·목표에 기반한 자율 AI

기존 코드의 기반: `game/mind.js`에 목격·사건·의심·알리바이 비교가 있다. 하지만 낮에는 대부분 무작위 배회이며, 일부 추격·치료 행동은 실제 전체 좌표·부상 상태를 직접 읽는다.

- [ ] 전체 게임 상태와 각 AI의 정당한 개인 관측을 분리한다.
- [ ] 거리·시야각·벽 가림·밝기·소리를 거친 정보만 기억에 넣는다.
- [ ] 직접 목격·전해 들은 말·추측·직업 능력으로 아는 사실을 구분하고 출처·시간·불확실성을 보존한다.
- [ ] 같은 소문이 반복돼도 독립된 증거 여러 개로 세지 않는다.
- [ ] 성격을 역할과 분리한다. 신중함·호기심·경계심·협력성·주장성·인내·공포 반응 등이 실제 선택에 반영되게 한다.
- [ ] 의심·신뢰·위험·현재 목표에 따라 미행·질문·조사·동행·보호·회피·발언·투표를 선택한다.
- [ ] 행동의 시작 이유·유지 조건·중단 조건을 둔다. 매 순간 무작위로 목표를 바꾸지 않는다.
- [ ] 시야에서 놓친 상대는 마지막 목격 위치에서 수색한다. 숨은 실제 현재 좌표를 읽지 않는다.
- [ ] 발소리만 듣고 이름·직업·정확한 좌표까지 알지 않게 한다.
- [ ] 반증과 새 정보가 나오면 의심과 행동을 바꿀 수 있게 한다.
- [ ] 판단과 행동 이유를 검증용으로 확인할 수 있게 한다. 플레이어에게 비공개 역할을 노출하는 방식은 피한다.

- [ ] 발화자·대상·장소·시간·주장·부정·정정·출처·해석 불확실성을 보존한다.

- [ ] 외부 모델이 문장을 돕더라도 이동·공격·투표의 최종 판정은 공통 게임 규칙에서 처리한다.

## 실행과 검증 위치

```text
npm ci
npm run dev
http://127.0.0.1:5174/?look=reference
http://127.0.0.1:5174/

node tools/build-reference-models.mjs
node tools/fit-reference-layout.mjs
npm run build
git diff --check
```

- `npm ci`는 필요한 경우에만 실행한다. 모델 원본을 수정한 경우 GLB를 다시 출력한다.
- 개발 서버가 이미 실행 중이면 중복 실행하지 않는다. 다른 작업이나 사용자의 프로세스를 임의 종료하지 않는다.
- 원본 구도 버튼 또는 R로 기준 화면에 복귀한다. 사진 비교 모드가 아닌 실제 3D 화면을 캡처한다.
- 현재 확인: 빌드·diff 검사 통과, 브라우저 오류 로그 없음, 구도 복귀와 복도 이동 확인. 표시는 약 60 FPS였으나 여러 기기의 성능 보장은 아니다.
- 남은 검증: 모든 모서리·천장·이동 경로의 충돌, 원본과 전체 시각 품질 일치, AI 한 판, 온라인, 음성·자연어, 여러 기기 성능.
- 빌드의 일부 JS 묶음이 500 kB를 초과한다는 경고는 남아 있다.

구현·검증 결과와 사용자의 실제 검토를 구분한다. 사용자가 승인하지 않은 시각 품질이나 미실행 기능을 완료로 표시하지 않는다. 다음 작업에서 변경한 항목, 검증 결과와 남은 문제를 이 문서에 갱신한다.
